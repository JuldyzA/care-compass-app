# Systems Analysis and Design Group Project

## 📌 Project Overview

This repository contains a **Systems Analysis and Design (SAD) group project** focused on the analysis, design, and planned implementation of a real-world business information system using **ASP.NET MVC**, **ASP.NET Identity**, and **SQLite**.

The project follows standard **Software Development Life Cycle (SDLC)** practices, emphasizing requirements engineering, system modeling, architectural design, and secure data management.

---

## 🎯 Project Objectives

* Apply Systems Analysis and Design principles in a team environment
* Identify and document functional and non-functional requirements
* Design a secure, scalable system architecture
* Model relational data using a normalized database design
* Implement authentication and authorization using ASP.NET Identity
* Use SQLite as a lightweight relational database for development

---

## 🧩 System Features (Planned / Implemented)

### User Management (ASP.NET Identity)

* User registration and login
* Role-based authorization (Admin, User, etc.)
* Password hashing and security policies
* Account validation and access control

### Core System Features

* CRUD operations for core business entities
* Input validation (client-side and server-side)
* Error handling and logging
* Secure data access via Entity Framework

---

## 🏗️ System Architecture

The system follows the **ASP.NET MVC architectural pattern**:

* **Model** – Business entities and database models
* **View** – Razor views for UI presentation
* **Controller** – Handles requests, responses, and business logic

Additional layers include:

* **Service Layer** – Business rules and processing
* **Data Access Layer** – Entity Framework Core with SQLite

---

## 🗄️ Database Design

* Database Engine: **SQLite**
* ORM: **Entity Framework Core**
* Normalized relational schema (3NF)
* Primary and foreign key constraints
* Identity tables generated by ASP.NET Identity

---

## 🔐 Security Design

* Authentication and authorization using **ASP.NET Identity**
* Role-based access control (RBAC)
* Password hashing and salting
* Input validation and anti-forgery protection
